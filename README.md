Personal Portfolio Website

📌 Project Overview

This project is a personal portfolio website developed using **HTML** and **CSS**. It is designed to showcase my profile, skills, projects, and contact details in a clean, simple, and professional layout. The website is beginner-friendly and focuses on clarity, responsiveness, and good design practices.

---

🎯 Objective

The main objective of this project is to practice the fundamentals of frontend web development. It helps in understanding webpage structure, styling techniques, and responsive design while creating a professional online presence.

---

🛠️ Technologies Used

* **HTML5** – Used to structure the content of the webpage
* **CSS3** – Used for styling, layout, and visual design
* **GitHub Pages** – Used to host the website online

---

🧩 Code Explanation

HTML is used to build the overall structure of the webpage, starting from the header to the footer. The header section displays my name and role, while the navigation bar allows users to move easily between different sections of the website.

The head section includes meta tags to support all character sets and ensure the website is responsive on different screen sizes. Internal CSS is used to manage the design of the webpage, including colors, fonts, spacing, and layout.

The website is divided into multiple sections such as profile, about me, skills, projects, and contact. Each section follows a card-style design with rounded corners and shadow effects to give a modern and professional look. A circular profile image is used to enhance visual appeal, and the footer contains copyright information.

Overall, the code demonstrates a simple, responsive, and user-friendly portfolio website using basic web technologies.

---

✨ Key Features

* Clean and simple user interface
* Responsive design for mobile and desktop devices
* Easy navigation using anchor links
* Card-style layout with modern styling
